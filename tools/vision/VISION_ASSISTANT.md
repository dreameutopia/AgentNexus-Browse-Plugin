# 视觉助手：观察与指引

视觉助手负责“看懂并教我”，Vision Action 负责“看懂并替我做”。二者都能读取画面、滚动和检查 DOM；区别是执行职责，不是感知技术。

| 用户目标 | 使用角色 | 完成标准 |
| --- | --- | --- |
| 页面导读、翻译、解释报错、寻找入口、指导填写 | 视觉助手 | 给出有证据、可照着执行的说明 |
| 点击、填写、拖拽、导航并完成业务流程 | Vision Action | 实际执行并核对页面结果 |
| 结构明确的控件和表单自动化 | Auto Action | 通过结构化控件完成并验证 |
| 全量取数、批量处理和导出 | 数据收割机 | 有完整性依据的数据结果 |

## 观察工具

所有点和区域使用**完整原始视口截图**的 0–1000 x/y 坐标。除等待工具外，必须提供最新 screenshotId。读取工具不点击、不聚焦、不悬停、不输入，也不接受任意脚本。

| 工具 | 行为与边界 |
| --- | --- |
| `screenshot` | 视觉助手强制 `mode=observe`，用 `tabs.captureVisibleTab` 获取完整视口图，不主动附加调试器；附标签页、URL、时间、滚动位置及截图 ID |
| `vision_read` | 读取当前视口或 region 相交的已渲染 DOM 文字和控件状态；point 检查目标及少量祖先。不返回输入值、处理器或页面 JS 状态；输出截断有显式标记 |
| `vision_read_scroll` | 四向滚动。省略 point 时滚文档；指定 point 时选最近可滚动组件，支持可访问的同源 iframe。百分比相对目标容器的 client 尺寸；报告实际位移及边界。到边界不继续滚父容器 |
| `vision_read_zoom` | 裁剪最新原始截图像素，最多 2048 边长／4MP。保留原图来源和实际裁剪区域；不改变网页缩放，不创建可操作截图 ID，不接受放大图坐标 |
| `vision_read_wait` | 300–5000ms 的采样预算，检查加载状态与几何采样，返回新完整截图。预算不含截图和浏览器传输时间；用户取消时停止后续步骤 |
| `generic_wait` | 较长的定时等待，单位秒；超过 600 自动限制为 600，可随时停止。等待后另等 3 秒取得新图，时间到达不代表业务完成 |

滚动消耗来源截图，即使部分失败也不能重放；随后视觉循环获取新图。普通读取、放大不消耗原图。观察与 GUI 驱动共用串行队列，读取前后核验活动标签页、URL、文档和视口。观察截图以隔离世界的 document 引用识别同 URL 重载，不依赖调试会话；观察 ID 不能用于 GUI 输入。等待重拍也使用观察通道。Chromium 每秒最多两次可见标签截图，队列统一节流。等待允许滚动偏移变化，但不会跨导航或切页继续。

滚动采用固定 DOM 滚动实现，不发送点击、焦点、鼠标移动、滚轮或键盘事件。页面仍可能因滚动触发懒加载、已读等业务事件，不能承诺完全无副作用。跨域不可访问 iframe 或变换后无法可靠映射的 iframe 交由用户滚动。

DOM 与截图不是同一时刻的完整世界模型。读取范围是与视口／区域相交的渲染节点，部分相交文本节点可能包含视口外文字；遮挡、Canvas、WebGL、封闭 Shadow DOM 和 iframe 正文的覆盖不完整。`geometryStable` 不代表内容、网络、动画或业务完成。局部放大也不能恢复原图缺失的细节。

## 能力上限

`utils/agents/vision-assistant-policy.ts` 是内置视觉助手工具白名单。运行时按稳定智能体 ID `Vision-Assistant` 应用该上限，覆盖预设、附加工具、预选技能和运行中技能扩容。需要写入／代操作工具的技能不进入发现清单或激活上下文；执行入口再次检查实际调用，模型即使虚构或调用未公布工具也不能执行。

核心 `browser_get_page_text` 保留用于用户明确要求的全文阅读，在视觉助手中只能以空参数读取当前活动页，不能借 tabId 访问其他页面。其结果可能含屏幕外正文，不作为当前可见状态证据。没有加入 `browser_page_exec` 或 `browser_inject_script`，也不依赖提示词中的“只读 JS”来实现权限隔离。

用户需要执行时，视觉助手说明应切换的智能体，交接目标、已有证据、用户已完成步骤与剩余事项；不会声称已经替用户执行或自动转交。

## 视觉循环与提示词

普通读取、计划、技能等不触发无意义的重截图；主动截图／等待返回的完整图直接复用。后续可能改变页面的工具仍要求新图，未知工具采取保守续拍。截图和裁剪图通过多模态图片通道传递，不重复塞进 JSON 工具正文；裁剪图显式说明只用于阅读。

提示词要求按需观察、单次调用一个观察工具、小步滚动、无进展停止，并区分截图事实、DOM／全文补充与一般经验。用户自行点击或展开后刷新证据，不能猜测后续业务行为或把预期结果当作事实。

## 验证

- `npm run test:tools`：观察参数边界、独立 realm 荷载、密码值排除、组件滚动不点击／聚焦、到边界停止、图片续拍决策、运行时／技能能力上限和执行拦截。
- `npm run test:vision`：共享 GUI 驱动、坐标、截图有效性、取消与输入生命周期。
- `node tests/vision/browser-probe.mjs`：独立临时 Chromium，真实视口、嵌套与横向滚动、同源 iframe、等待重拍、像素裁剪及无点击／焦点／滚轮事件验证。

驱动与观察测试不能替代具体模型的图像理解质量或真实业务站点验收。
