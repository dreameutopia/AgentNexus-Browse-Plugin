# 浏览器窗口绑定（Beta）

输入框底部、模型选择器右侧的屏幕按钮可将当前会话绑定到侧边栏所在窗口，或其他已有的普通浏览器窗口。

## 行为

- 默认关闭；没有 `browserScope` 时，工具使用原生 Chrome API，保留原有的目标解析、跨窗口查询和窗口聚焦行为。
- 开启后，页面工具只访问绑定窗口内的标签页。默认活动页、显式标签 ID、标签列表、内容搜索、URL 复用、批量关闭、新建页、脚本注入和 CDP 命令均遵守同一边界。
- 标签可以在绑定窗口内部激活；工具不会主动将窗口聚焦到前台。
- 自动首拍、续拍、OCR 内部截图、页面上下文和页面高亮使用相同绑定。插件宿主别名与工作流子步骤继承绑定。
- 页面净化在绑定模式使用独立的标签页网络规则，撤销不触碰原有全局规则；标签移出或关闭时清理这些规则。持续网络捕获保存自己的作用域，读结果时校验标签归属，标签移出时停止采集。
- 被拖出窗口的标签不再可访问。绑定窗口关闭时，正在执行的会话任务取消并按错误终态收尾，输出可渲染、持久化的 `<api-error>` 卡片，不把它误报为用户停止，也不转到其他窗口续跑。
- 配置按会话保存在 `chrome.storage.session`；浏览器重启或扩展重载后恢复关闭状态，不复用可能失效的窗口 ID。窗口关闭后，后台清除所有引用该窗口的会话及草稿绑定，各侧边栏通过存储事件同步回跟随模式；下一次用户请求使用新设置。后台启动还会补查失效绑定。
- 任务运行、发送准备及停止收尾时禁用整个操作窗口按钮，已经打开的菜单自动收起。后台继续检查跨侧边栏占用状态，拒绝绑定、换窗和关闭绑定等所有用户切换。系统处理已关闭窗口不受用户切换锁限制，但必须在会话锁内重读目标，避免覆盖新绑定。已有运行持有独立的绑定快照；多个会话没有共享的全局目标窗口。

窗口绑定限制页面操作范围，并不隔离账户、Cookie、站点存储、书签或下载管理器。远端 MCP 的执行环境不由此扩展管理；插件调用本扩展的页面能力时受绑定限制。

## 实现

- `tools/browser/browser-scope.ts`：`BrowserWindowTarget` 统一管理不可变的可选 `BrowserScope` 描述对象；调用者只传递执行上下文，不自行选择全局窗口。关闭时直接返回原生对象；开启时检查窗口和标签归属、限制枚举与创建、抑制窗口聚焦，并在注入和 CDP 下发前复核。
- `executeWithBrowserScope`：单次执行的焦点模拟租约。后台文本和视觉输入使用焦点模拟，执行结束关闭；关闭模拟失败时脱离调试器，避免影响后续默认模式。
- `tools/browser/scope-errors.ts`：统一错误码、操作名、窗口/标签 ID、原始异常和结果不确定标志。读取、派发、清理均有等待上限；取消或超时不代表已派发的原生操作被撤销，变更类操作提示先观察再重试。
- `utils/browser-window-binding.ts`：由后台代理写入，按会话串行化保存与运行登记，检查其他侧边栏的运行/停止状态。发送按钮捕获一次选择结果，准备高亮、草稿迁移、模型信息和工具共享该快照；保存失败阻止发送，后台发现配置变更拒绝启动。
- 绑定保存使用版本化的专用后台 Port，并核对回复的请求编号，避免广播消息被其他监听器的空回复抢先应答。成功、失败或超时均释放连接；后台未更新或连接断开时提示重新加载扩展、重开侧边栏。后台暂保留旧消息协议，兼容尚未关闭的旧侧边栏。
- `BrowserWindowPicker.vue`：窗口选择、关闭状态、跨视图同步和新会话草稿迁移。
- `utils/browser-window-lifecycle.ts`：先监听再检查窗口是否存在，覆盖准备期间的关闭竞态；后台准备与本地/后台会话引擎共享检测规则，结束后释放监听。关闭导致的中止保留错误原因，工具结算与历史协议继续遵循现有引擎的单出口收尾。
- 工具上下文不会混入模型可写参数；跨后台消息使用单独的受信封套。窗口解析失败不会降级为隐式目标。
- 回调式调用保留作用域门面的 `runtime.lastError` 生命周期；`tabs.connect` 保持同步 Port 接口，校验前缓存有界消息，标签移出/关闭或取消时释放连接。持续网络捕获使用独立作用域，避免复用已结束的工具租约。

Chrome 没有“检查标签归属并执行操作”的原子 API。实现会在目标解析、注入和 CDP 执行等边界复核归属；不能将其当成独立浏览器进程或权限沙箱。原生文件选择器、权限弹窗与页面自行弹出的新窗口可能需要人工处理。

## 验证

```sh
npm run compile
npm run test:tools
npm run test:chat-ui
npm run test:conversation-runtime
npm run test:plugins
npm run test:system-context
npm run test:i18n
npm run test:text-browser
npm run test:window-binding-browser
npm run build
```

`window-binding.test.ts` 检查默认兼容性、并发作用域、越界 ID、批量关闭、注入边界、截图、页面上下文、焦点释放、拖出标签和关闭窗口。

`browser-window-picker.test.mjs` 挂载真实 Vue 组件，检查开关、两个窗口选项、草稿迁移、忙碌禁用、失效绑定、关闭与会话切换。

`window-closure-engine.test.ts` 使用真实会话引擎检查窗口关闭后的流式取消、守卫等待取消、唯一错误事件、部分输出保留、终态落库和实际错误卡片渲染。后台运行时回归另覆盖预运行压缩期间关闭窗口，以及绑定自动清理。

`window-binding-browser-probe.mjs` 使用临时用户目录启动无界面 Chromium，创建两个真实窗口，验证后台可信输入、CDP 截图、越界拒绝、没有激活命令和焦点模拟释放。扩展的标签/窗口 API 在此通过适配器连接 CDP 目标；它不代替安装扩展后的桌面前台焦点验收。

发布前手动验证：A 绑定、B 正常输入；A 内新建和切换标签；在 B 开侧边栏仍操作 A；拖出 A 的标签；关闭 A 后继续调用；两个会话分别绑定不同窗口；关闭 Beta 后恢复原有行为。另需覆盖可见、完全遮挡、最小化、跨域 iframe、DevTools 冲突与原生弹窗。

Windows 的窗口遮挡和浏览器后台调度会影响渲染、定时器及截图更新。Beta 不承诺最小化或完全遮挡时所有视觉任务稳定运行。
