Privacy Policy

Last Updated: December 8, 2025

Important: AgentNexus Browse Helper is committed to protecting your privacy. We do NOT collect, store, or transmit your personal sensitive information to our servers. All data processing is done locally.

1. Information Collection and Use

1.1 Information We Access

This extension may access the following information during usage (processed locally only, NOT uploaded to servers):

  • Browsing Data: Current tab's URL, title, and content (only when you explicitly use related features)
  • Browsing History: For history search and navigation features
  • Bookmarks Data: For bookmark search and management features
  • Local Storage: To save your settings and preferences
  • Screenshot Data: Temporarily generated only when you use screenshot features, not uploaded

1.2 Information We Do NOT Collect

  • ❌ Passwords or other credentials
  • ❌ Payment information or credit card data
  • ❌ Personal identification information (name, address, phone, etc.)
  • ❌ Cookie data
  • ❌ User behavior tracking data

2. Permission Explanations

This extension requires the following permissions to provide full functionality. Each permission's specific purpose is explained below:

📋 tabs

Purpose: Access tab information (URL, title), execute page automation

Data Processing: Processed locally only, not uploaded

📝 activeTab

Purpose: Access current page when you actively click the extension icon

Data Processing: Accessed only when you explicitly operate

💉 scripting

Purpose: Execute automation scripts on web pages (e.g., auto-fill forms, clicking)

Data Processing: Scripts execute locally only, no data transmission

🔍 debugger

Purpose:

  • Capture network request data (for network analysis tools)
  • Monitor page performance metrics
  • Implement advanced automation features (e.g., wait for specific network requests to complete)

Important Note: This permission is used ONLY to provide advanced browser automation features, NOT for monitoring or stealing user data. All debugging data is processed locally.

🌐 <all_urls>

Purpose: Provide automation and assistance features on any website

Data Processing: Access page content only when you actively use features, no background monitoring

📚 history

Purpose: Provide browsing history search functionality

Data Processing: Read only, not modified or uploaded

⭐ bookmarks

Purpose: Provide bookmark search and management functionality

Data Processing: Read only, not modified or uploaded

⬇️ downloads

Purpose: Save screenshots, export data, etc.

Data Processing: All downloaded files are saved to your local computer

🌐 webRequest

Purpose: Intercept downloads of specific file types (e.g., intercept PDFs for preview functionality)

Data Processing: Used only to modify response headers, does not collect request data

💾 storage

Purpose: Save your settings, preferences, and cached data

Data Processing: All data is saved in local browser storage

🔌 nativeMessaging

Purpose: Communicate with locally installed AgentNexus application

Data Processing: Transmitted only between local devices, not over the internet

3. Data Storage

3.1 Local Storage

  • All user settings and preferences are saved in browser's local storage
  • Index data (for search features) is saved in local IndexedDB
  • This data is NOT synced to the cloud (unless you use browser's sync feature)

3.2 Cached Data

  • AI model caches are saved locally to improve performance
  • You can clear caches anytime in extension settings

4. Third-Party Services

This extension may connect to the following third-party services (only when configured by you):

  • OpenAI-compatible APIs: If you configure an API key, the extension sends requests to your specified API endpoint
  • ModelScope / Alibaba Cloud: For AI model inference (only when you choose to use)

Important: The privacy policies of these services are defined by their respective providers. Please review the privacy policies of the respective services.

5. Data Security

  • All sensitive operations are completed locally, no upload to our servers
  • Your API keys are saved using browser's secure storage mechanism
  • We do NOT log or store your browsing history to remote servers

6. Your Rights

You can always:

  • View Data: All data is saved locally, viewable through browser developer tools
  • Delete Data: Clear all data in extension settings, or directly uninstall the extension
  • Stop Using: Disable or uninstall the extension anytime

7. Children's Privacy

This extension is not specifically targeted at children under 13. We do not knowingly collect personal information from children.

8. Policy Updates

We may update this privacy policy from time to time. Significant changes will be notified when the extension is updated. Please review this policy regularly for the latest information.
