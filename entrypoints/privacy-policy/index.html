隐私政策

最后更新日期: 2025年12月8日

重要提示: AgentNexus Browse Helper 致力于保护您的隐私。我们不会收集、存储或传输您的个人敏感信息到我们的服务器。所有数据处理均在本地完成。

1. 信息收集与使用

1.1 我们收集的信息

本扩展程序在您使用过程中可能访问以下信息（仅在本地处理，不上传到服务器）：

  • 浏览数据: 当前标签页的 URL、标题和内容（仅在您明确使用相关功能时）
  • 浏览历史: 用于提供历史搜索和导航功能
  • 书签数据: 用于书签搜索和管理功能
  • 本地存储: 保存您的设置和偏好
  • 截图数据: 仅在您使用截图功能时临时生成，不会上传

1.2 我们不收集的信息

  • ❌ 密码或其他身份凭证
  • ❌ 支付信息或信用卡数据
  • ❌ 个人身份信息（姓名、地址、电话等）
  • ❌ Cookie 数据
  • ❌ 用户行为追踪数据

2. 权限说明

本扩展需要以下权限以提供完整功能。每个权限的具体用途说明如下：

📋 tabs（标签页）

用途: 访问标签页信息（URL、标题），执行页面自动化操作

数据处理: 仅在本地处理，不上传

📝 activeTab（活动标签页）

用途: 在您主动点击扩展图标时访问当前页面

数据处理: 仅在您明确操作时访问

💉 scripting（脚本注入）

用途: 在网页中执行自动化脚本（如自动填表、点击等）

数据处理: 脚本仅在本地执行，不传输数据

🔍 debugger（调试器）

用途:

  • 捕获网络请求数据（用于网络分析工具）
  • 监控页面性能指标
  • 实现高级自动化功能（如等待特定网络请求完成）

重要说明: 此权限仅用于提供高级浏览器自动化功能，不会用于监控或窃取用户数据。所有调试数据仅在本地处理。

🌐 <all_urls>（访问所有网站）

用途: 在任意网站上提供自动化和辅助功能

数据处理: 仅在您主动使用功能时访问页面内容，不会后台监控

📚 history（浏览历史）

用途: 提供历史记录搜索功能

数据处理: 仅读取，不修改或上传

⭐ bookmarks（书签）

用途: 提供书签搜索和管理功能

数据处理: 仅读取，不修改或上传

⬇️ downloads（下载）

用途: 保存截图、导出数据等

数据处理: 所有下载文件保存在您的本地计算机

🌐 webRequest（网络请求）

用途: 拦截特定文件类型的下载（如拦截 PDF 以提供预览功能）

数据处理: 仅用于修改响应头，不收集请求数据

💾 storage（存储）

用途: 保存您的设置、偏好和缓存数据

数据处理: 所有数据保存在本地浏览器中

🔌 nativeMessaging（本地消息传递）

用途: 与本地安装的 AgentNexus 应用程序通信

数据处理: 仅在本地设备之间传输，不经过互联网

3. 数据存储

3.1 本地存储

  • 所有用户设置和偏好保存在浏览器的本地存储中
  • 索引数据（用于搜索功能）保存在本地 IndexedDB 中
  • 这些数据不会同步到云端（除非您使用了浏览器的同步功能）

3.2 缓存数据

  • AI 模型缓存保存在本地以提高性能
  • 您可以随时在扩展设置中清除缓存

4. 第三方服务

本扩展可能会连接到以下第三方服务（仅在您配置后）：

  • OpenAI 兼容 API: 如果您配置了 API 密钥，扩展会向您指定的 API 端点发送请求
  • ModelScope / 阿里云: 用于 AI 模型推理（仅在您选择使用时）

重要: 这些服务的隐私政策由各自的提供商制定。请查阅相应服务的隐私政策。

5. 数据安全

  • 所有敏感操作都在本地完成，无需上传到我们的服务器
  • 您的 API 密钥使用浏览器的安全存储机制保存
  • 我们不会记录或存储您的浏览历史到远程服务器

6. 您的权利

您随时可以：

  • 查看数据: 所有数据都保存在本地，可通过浏览器开发工具查看
  • 删除数据: 在扩展设置中清除所有数据，或直接卸载扩展
  • 停止使用: 随时禁用或卸载扩展

7. 儿童隐私

本扩展不专门针对 13 岁以下的儿童。我们不会故意收集儿童的个人信息。

8. 政策更新

我们可能会不时更新本隐私政策。重大变更会在扩展更新时通知您。请定期查看本政策以了解最新信息。
